## 🧠 Forgetting curve model (Ebbinghaus / SM-2 style)

Review intervals: **same day (13h + 20h) → 1d → 3d → 7d → 14d → 30d → 90d → mastered**

After each review, memory status adjusts the next interval:
- 🟢 Easy → advance to the next interval
- 🟡 Need practice → repeat the current interval
- 🔴 Forgotten → reset to 1d
